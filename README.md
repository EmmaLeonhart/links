# links.emmaleonhart.com

Emma Leonhart's link hub, served at <https://links.emmaleonhart.com> via GitHub Pages.

A single self-contained `index.html` on the shared visual identity (`identity.css`,
the same Lacquer dark/light tokens as emmaleonhart.com). Sections: Research & Writing,
Code & Projects, Interactive Tutorials, Professional & Social.

## Deploy

GitHub Pages serves the repo root. `CNAME` pins the custom domain
`links.emmaleonhart.com`. No build step.

## Identity

`identity.css` is a copy of the canonical file from
[emmaleonhart.com](https://github.com/EmmaLeonhart/emmaleonhart.com)
(`pages/identity.css`). Keep it in sync with the source of truth there.

This repo is mirrored as the `repos/links` submodule inside emmaleonhart.com.
The main site's `/links` path is a redirect stub pointing here.
